================================================================================
             CADDOCK DIVIDER TOPOLOGY (unchanged from Rev A)
================================================================================

     HV Input ──[FUSE]──► AB1 ──R── AB2 ──R── AB3 ──R── AB4 ──R── AB5 ──R── AB6 ──R── AB7
                                │              │         │         │                    ▲
                                │             tap       tap       tap                   │
                                │              │         │         │                    │
                       CD1 ──R── CD2 ──R── CD3 ──R── CD4 ──R── CD5 ──R── CD6 ──R── CD7
                        ▲       │        tap       tap       tap                   │
                        │       │         │         │         │                    ▼
                   (from AB2)   │        MUX36D04 bridges these                  GND
                                ▼
                          OUTPUT → OPA828 → TPD4E1B06 → MUX36D08 S6

Pair AB: Dividers A and B, all pins tied (A1-B1, A2-B2, ... A7-B7)
Pair CD: Dividers C and D, all pins tied (C1-D1, C2-D2, ... C7-D7)
Series: AB2 → CD1, CD2 → Output AND AB7 (feedback)
Ground: CD7 → GND


================================================================================
             MUX36D04 DIVIDER TAP MAPPING
================================================================================

MUX36D04 address selects which divider taps to bridge:

  Address   A1  A0   MUX_A Source   MUX_B Source   Ratio    Range
  -------   --  --   -----------    -----------    ------   --------
     0       0   0   AB3            CD3            ÷10      ±50V
     1       0   1   AB4            CD4            ÷100     ±500V
     2       1   0   AB5            CD5            ÷1000    ±5000V
     3       1   1   (spare)        (spare)        --       --

MUX_A Drain (DA) tied to MUX_B Drain (DB) → bridges selected taps.
EN hardwired LOW (always enabled) → some tap always bridged.
Use address 3 (spare, unconnected sources) as "off" state.

                    ┌────────────────┐
        A0  1  ─────┤                ├───── 16  A1
        EN  2  ─────┤                ├───── 15  GND
       VSS  3  ─────┤                ├───── 14  VDD
       S1A  4  ─────┤   MUX36D04    ├───── 13  S1B
       S2A  5  ─────┤   (TSSOP-16)  ├───── 12  S2B
       S3A  6  ─────┤                ├───── 11  S3B
       S4A  7  ─────┤                ├───── 10  S4B
        DA  8  ─────┤                ├───── 9   DB
                    └────────────────┘

EN is ACTIVE HIGH: EN=HIGH → switches enabled, EN=LOW → all off.
Hardwired ON: tie EN to VDD.


================================================================================
             OPA828 PINOUT (SOIC-8, voltage follower)
================================================================================

                    ┌──────────────┐
        NC  1  ─────┤              ├───── 8  NC
       IN-  2  ─────┤              ├───── 7  +VS
       IN+  3  ─────┤   OPA828     ├───── 6  OUT
       -VS  4  ─────┤              ├───── 5  NC
                    └──────────────┘

Voltage follower wiring:
  IN+ (pin 3) = signal input (from CD2 divider output)
  IN- (pin 2) = tied to OUT (pin 6) for unity gain
  OUT (pin 6) = buffered output → TPD4E1B06 → MUX36D08 S6

NOTE: Verify this pinout against the actual OPA828 datasheet before wiring.

================================================================================
                    NOTES & WARNINGS
================================================================================

HIGH VOLTAGE SAFETY:
  - Maximum input: ±5000V DC (with ÷1000 divider)
  - Always use HV probe and proper PPE
  - Verify HV source is off and discharged before touching
  - Maintain creepage: >1mm per 100V on stripboard
  - Keep HV traces well separated from low-voltage circuitry

OPA828 STABILITY:
  - OPA828 has 1.5 GHz GBW - may oscillate with capacitive loads
  - Keep output trace to TPD4E1B06/MUX36D08 short
  - If oscillation occurs, add 10-50Ω series resistor at OPA828 output
  - Input capacitance of MUX36D04 drains adds to load

MUX36D04 LEAKAGE:
  - Rated <1pA at 25°C - critical for nanovolt measurements
  - Avoid flux residue on mux signal pins (clean with IPA)
  - Temperature affects leakage exponentially - keep cool

STRIPBOARD CONSIDERATIONS:
  - Cut copper strips between adjacent signal traces to prevent leakage
  - Consider guard rings around sensitive nodes (CD2, OPA828 input)
  - Use Teflon standoffs if possible for high-impedance nodes
